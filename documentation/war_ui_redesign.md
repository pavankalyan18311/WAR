# WAR Website Redesign Specification

## Objective

Redesign the entire website from the current generic fashion store UI into a premium, modern, oversized streetwear brand experience.

Brand Name: WAR

WAR is not a marketplace.

WAR sells only premium oversized t-shirts.

The design should feel like a mix of:

* Represent Clothing
* Fear of God Essentials
* Cole Buxton
* MANIAC India
* UNIQLO minimalism
* Nike premium campaign pages

The experience should feel production-ready and suitable for a premium D2C clothing brand.

---

# Design Direction

## Brand Personality

* Bold
* Minimal
* Premium
* Masculine
* Streetwear
* Luxury Basics
* Clean

Avoid:

* AI-themed sections
* Cartoon styling
* Generic ecommerce templates
* Bright colorful gradients
* Excessive animations

Use:

* Dark luxury aesthetic
* Large typography
* High quality lifestyle photography
* Premium spacing
* Minimal color palette
